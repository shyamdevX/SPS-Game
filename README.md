# 🎮 Stone Paper Scissors – Web Based Game

A responsive and interactive Rock Paper Scissors game built from scratch using core web technologies. Focused on clean UI and pure JavaScript logic.

### 🚀 Live Demo
👉 https://shyamdevx.github.io/SPS-Game/

### About
Built this project to understand core JavaScript concepts like DOM manipulation, event listeners, and game logic. Used custom images for Rock, Paper and Scissors instead of default buttons to give it a unique gaming look.

### Features
- User vs Computer
- Dynamic result display
- Live score counter
- Fully responsive for all devices
- Custom UI with gaming background

### Tech Stack
- HTML5
- CSS3 (Flexbox & Custom Styling)
- JavaScript (Vanilla)

### How to Run Locally
1. Download / Clone the repo
2. Open index.html in browser
